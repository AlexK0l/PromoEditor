# PromoEditor — один контролируемый платный OpenAI-тест актуального main на Time4VPS

Этот сценарий только для **изолированной** службы `promoeditor-preview`
на `127.0.0.1:18081`. Не обновляет
`/opt/promoeditor`, не перезапускает RegionalResearch, Caddy и рабочий
`promoeditor`.

## Перед запуском

1. Проверьте один завершённый **бесплатный** прогон новой версии:
   `/api/analyze-assets=200`, `/api/generate=200`, `Both formats and ZIP ready`,
   PNG/SVG и точные проверенные характеристики в ZIP.
2. Остановите **только** временную службу: `systemctl stop promoeditor-preview`.
3. Дождитесь прекращения интенсивных заданий RegionalResearch. Должны быть
   одновременно: `MemAvailable>=1400 MiB`, потребление RegionalResearch
   **менее 640 MiB**, свободный диск более 1 GiB, все три production unit active.
4. Проверьте корректное время и биллинг вашего OpenAI API-аккаунта.
   `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и `gpt-4.1-mini`
   доступны только при наличии разрешений у конкретного проекта API.
   Рабочий ключ нужен в защищённом root-only env-файле; ни его содержимое,
   ни данные платёжного кабинета никогда не копируйте в чат.
5. Используйте только точный **40-символьный проверенный SHA** из `main`.
   Сверьте SHA с проверками GitHub Actions. Скрипт Preview необходимо
   заново извлечь из этого SHA и запустить `bash /root/promoeditor-main-stage.sh "$SHA" paid`.
   Рабочая версия PromoEditor на VPS от этого не обновляется.
   Скрипт останавливается **без запуска**, если RAM/службы/диск не готовы;
   при уже работающем preview он тоже отказывает, чтобы не создать дубликат.

## Браузер и стоимость

Для доступа используйте только SSH-туннель:

```powershell
ssh -N -L 18081:127.0.0.1:18081 root@YOUR_VPS_IP
```

Откройте `http://127.0.0.1:18081`, нажмите Ctrl+F5 и проверьте, что
`OpenAI` доступен. Примените эталон ZubrTrail 500, загрузите одну
**подлинную** фотографию, свой логотип и чертёж по желанию. Не включайте
дополнительный платный анализ материалов, «AI-постер без эталона»
или экспериментальные AI-концепции. Для обычной проверки выберите основную
функцию «Оформить с помощью OpenAI» и качество «Стандартное».

Клик `Создать промо` требует подтверждения: **до 3 платных вызовов**
(один `Responses` для размещения элементов, два `Images` для фонов).
Иные сторонние запросы не входят в это число. На сервере источник
OpenAI вызывает `max_retries=0`, но сетевой таймаут не гарантирует, что
API-поставщик не списал оплату. В отличие от отдельной кнопки
«Проанализировать материалы» базовый отбор фотографий бесплатно
выполняется локально.

**Нажимать только один раз.** Если интерфейс показывает «Создаём…» более
нескольких минут, не перезагружайте страницу и не повторяйте платный запрос
до анализа журнала и частичных кэшей. Программа отдельно сохраняет
успешно полученные платные фоны на ограниченный срок, но повторная оплата
не может быть исключена при сбое до записи кэша.

## Что считать успехом

- HTTP 200 на `POST /api/generate`.
- В системном журнале все этапы `Render started` → `Input images decoded`
  → `SVG 4x3 composed` → `PNG/JPEG 4x3 rasterized`
  → `SVG 9x16 composed` → `PNG/JPEG 9x16 rasterized`
  → `Both formats and ZIP ready`.
- Макеты 4:3 и 9:16 имеют непротиворечивые композиции.
- В SVG оригинальный полуприцеп, логотип и чертёж не нарисованы AI:
  это отдельные встроенные изображения. Проверенные ТТХ, 6 527 000 ₽
  с НДС и телефоны — отдельные текстовые объекты без подмен.
- В ZIP присутствуют исходные загрузки без изменения байтов.
- После генерации `promoeditor`, `regionalresearch`, `caddy` остаются active.
- `memory.events` у `promoeditor-preview`: `oom_kill=0`.
- Нет `Fontconfig error: No writable cache directories` для этого запуска.

Если что-то не совпало, **не считать PR готовым к merge**. Снимите
`journalctl -u promoeditor-preview -n 100 --no-pager`,
`systemctl show promoeditor-preview -p MemoryCurrent -p MemoryPeak -p MemoryMax`
и `free -h`; не публикуйте личные ключи.

После завершения остановите только временный unit
`systemctl stop promoeditor-preview`, затем удалите временный env
`rm -f /run/promoeditor-preview.env` (делать **после** остановки).
Не очищайте платные кэши до анализа незавершённой транзакции.
