# PromoEditor main: художественный AI-макет + точный текст + AI-типографика

**Реализовано в main.** Основная кнопка «Создать промо» с включённым
«Оформить с помощью OpenAI» теперь использует `generation_mode=hybrid`
(историческое имя параметра) и функцию
`main._exact_typography_posters_sync()`.

## Основной производственный процесс

1. Из нескольких исходных фото сервер выбирает один главный ракурс. При
   отсутствии ручного выбора и проверенной сохранённой AI-оценки среди
   конкурирующих фото может использоваться **1 платный Responses-вызов**.
   Остальные фотографии не меняются.
2. Один **Images edit** заменяет старые маркировки только на выбранном
   полуприцепе (логотип/бренд/модель из формы). Он сохраняется в
   `rebranded_product.png`, исходный файл остаётся в ZIP нетронутым.
3. Два **Images edits** рисуют законченные художественные шаблоны 4:3 и
   9:16 с выбранным ребрендированным прицепом, визуальной иерархией и
   достаточными **пустыми областями**. В Images-промпте запрещены
   текст, цифры, псевдонадписи и декоративные дубли товара. Конвертация
   соотношений сторон происходит **без обрезки**; используется
   `preserve_artwork_without_crop()`.
4. Один **Responses vision** анализирует **оба фактически созданных**
   макета. Возвращает нормализованные координаты (`0..1000`) текстовых
   областей, исходного логотипа/чертежа и самого прицепа. Алгоритм
   валидирует рамки, отступы, пересечения с техникой и друг с другом.
   **Нет fallback на геометрический шаблон.**
5. `app/ai_exact_copy_render.py` собирает точные данные из
   **нормализованной формы**, не из ответов AI. Вписывает их в
   **редактируемые SVG-тексты**; исходный логотип и чертёж добавляются
   отдельно. Если факты не помещаются, запрос **завершается ошибкой
   без обрезания текста, многоточий или подмены цифр**.
6. После предварительной точной вставки текста **второй Responses
   vision** просматривает оба полученных изображения. AI выбирает только
   допустимую кириллическую гарнитуру (DejaVu Sans/Condensed),
   гармоничные цвета и масштаб, **не получает права переписать текст**.
   Алгоритм повторно рендерит тот же точный текст в новом AI-стиле.
   При низком контрасте цвета выбирается читаемый чёрный/белый.
7. Экспортируются PNG, JPEG и редактируемый SVG для каждого формата. Плакат выглядит как единая AI-композиция,
   а числовые данные и телефоны остаются алгоритмически точными.

## Конкретные файлы и API

- `app/ai_exact_copy_template.py` — запросы Images и Responses,
  промпты, структурированные JSON-схемы, кэш художественных шаблонов,
  AI-зон и финального стиля, две стадии preview/final.
- `app/ai_exact_copy_render.py` — сборка проверенного текста,
  валидация зон, вписывание **всех** строк без многоточий/обрезки,
  независимые текстовые слои CorelDRAW SVG.
- `app/product_rebrand_service.py` — отдельный кэш ребрендинга выбранного
  ракурса, из предыдущего релиза.
- `POST /api/generate` с `generation_mode=hybrid` —
  **новый основной режим** (поле сохранено для совместимости).
- `POST /api/ai-posters` — **старый полнорастровый режим**,
  оставлен для API-совместимости и скрыт из обычного интерфейса.
- `template` (бесплатный) не изменён.

## Выгрузка

`ai_typographic_posters.zip` включает:
- `ai_poster_4x3.png`, `ai_poster_9x16.png`, JPEG-версии;
- `corel_4x3.svg`, `corel_9x16.svg` —
  встроенный AI-растр + отдельные векторные текстовые узлы;
- `ai_template_4x3.png`, `ai_template_9x16.png` (пустые макеты);
- `rebranded_product.png`, `originals/product_photo.*` и доступные
  исходные логотип/чертёж/стилевой референс;
- `verified_copy.json`, `typography_layout.json`,
  `typography_style.json`, `selected_photo.json`, `brief.json`;
- `REVIEW_BEFORE_PUBLICATION.txt` с предупреждениями.

## Стоимость и защита

Обычный запуск: **3 Images edits + 2 Responses**. При нескольких
конкурирующих фото может быть ещё **1 Responses** для AI-выбора ракурса.
Пользователь подтверждает эту стоимость в основной форме. Контроль суточной
квоты `PROMO_AI_IMAGE_CALLS_PER_DAY`/`PROMO_AI_TEXT_CALLS_PER_DAY`.
После сбоев кэш каждого оплаченного шага позволяет не повторять его;
кэш конечного макета удаляется **только после успешного ZIP**.

Любой художественный AI-фон, визуальная верность прицепа и маркировка
требуют человеческой проверки перед публикацией. Точный SVG-текст не
означает, что AI-встроенные детали фотографии или товарный логотип
гарантированно без ошибок. Действующий сервер — только production main;
Preview не использовать и RegionalResearch/Caddy не изменять.
