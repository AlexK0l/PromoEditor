# OpenAI: платные запросы без суточных ограничений PromoEditor

В PromoEditor **нет дневного ограничения на вызовы OpenAI по умолчанию**.
Генерация изображений, AI-концепций и AI-анализ остаются платными по тарифу
вашего аккаунта OpenAI. Биллинг и rate limits поставщика не отключаются.

## Настройки (необязательные)

```dotenv
PROMO_AI_IMAGE_CALLS_PER_DAY=0
PROMO_AI_TEXT_CALLS_PER_DAY=0
```

- `0` или отсутствие соответствующей переменной: **без суточной квоты PromoEditor**.
- Положительное число, например `10`: добровольная суточная квота по UTC.
- `disabled` или `off`: **явный запрет** соответствующих платных запросов.
- Отрицательное и некорректное число: конфигурационная ошибка, запрос не отправляется.

`image`: `OpenAI.images.generate()` и `OpenAI.images.edit()` —
художественные фоны обоих форматов, полные AI-постеры и платное редактирование.

`text`: `OpenAI.responses.create()` — AI-планировки,
извлечение ТТХ и оценка материалов при явном включении.

В неограниченном режиме не требуется SQLite-база учёта вызовов.
Если добровольно указан положительный дневной предел, используется
прежняя атомарная схема SQLite в
`<PROMO_DATA_DIR>/openai_call_quota.sqlite3`: один счётчик по категории
и календарному дню UTC, безопасный для нескольких процессов. Такие квоты
ограничивают число попыток, но **не сумму расходов**. Ошибочные и
неопределённые ответы OpenAI не возвращают зарезервированные попытки.

## Time4VPS: как снять прежнюю блокировку

В версии **до этого изменения** значение `0` означало запрет.
После установки версии, содержащей данное исправление, те же строки `=0`
позволят генерацию без ограничений PromoEditor. **Не путайте поведение
версий:** пока VPS на старом коммите, `=0` по-прежнему блокирует OpenAI.
Чтобы убрать блокировку сразу на старой версии, можно временно поставить
большое положительное значение — оно всё ещё технически ограничивает
число вызовов. После безопасного обновления можно вернуть `0`
или вообще удалить обе переменные.

Серверная конфигурация: `/etc/promoeditor/promoeditor.env`, доступ
только root, права `0600`. Меняйте и перезапускайте **только**
`promoeditor`, не Caddy и не RegionalResearch. Не публикуйте ключ
OpenAI и содержимое env-файла.

Неограниченные запросы могут привести к существенным расходам. Настройте
своевременные уведомления/лимиты биллинга у OpenAI, не в PromoEditor.
Техническая защита VPS, проверка разрешений файлов и общий HTTP
rate throttle остаются без изменений.

Тесты без реальных платных вызовов:
`python -m pytest -q tests/test_ai_quota.py tests/test_ai_posters.py`.
