# OpenAI: устойчивые дневные квоты платных API-вызовов

Приложение хранит счётчики попыток в SQLite-файле
`<PROMO_DATA_DIR>/openai_call_quota.sqlite3`. В Docker Compose
`PROMO_DATA_DIR=/srv/promoeditor/instance/jobs` подключён к `promo_results`.
При установке на Time4VPS через systemd используется
`/var/lib/promoeditor/jobs`. Данные переживают перезапуск одного
Uvicorn-процесса и контейнера, если постоянный том сохранён.

## Конфигурация

В серверном env-файле (не в браузере):

```dotenv
PROMO_AI_IMAGE_CALLS_PER_DAY=24
PROMO_AI_TEXT_CALLS_PER_DAY=80
```

Лимиты отсчитываются по **календарным дням UTC**. Значение `0` означает
**запрет всех новых платных вызовов** соответствующего класса; отрицательные
и некорректные значения приводят к отказу в целях безопасности. Если параметр
не задан, применяются значения 24/80.

- `image`: `OpenAI.images.generate()` и `OpenAI.images.edit()`, включая
  AI-фоны обоих форматов и редактирование рекламной картинки.
- `text`: `OpenAI.responses.create()` — планирование трёх компоновок
  AI PRO, AI-извлечение характеристик из документов и AI-оценка исходных
  изображений.

Резервирование одной попытки происходит **непосредственно до** вызова SDK.
SQLite `BEGIN IMMEDIATE` предотвращает превышение суммарной квоты
несколькими потоками или процессами, работающими с одним файлом БД.
Результаты не возвращают квоту при ошибке или таймауте OpenAI: неизвестно,
успел ли поставщик обработать и тарифицировать запрос.

Счётчики **не привязаны к IP**, поэтому Caddy / системный прокси не
позволит нескольким пользователям обойти общий лимит. Это глобальная
квота установки, не индивидуальные аккаунты.

## Ограничения и что это НЕ гарантирует

1. Квоты ограничивают **число попыток API**, но **не сумму в долларах**.
   Стоимость зависит от модели, разрешения, качества и тарифа OpenAI.
   Отдельно настройте финансовый бюджет и уведомления в вашем аккаунте.
2. Это не платёжная отчётность и не учёт реальных успешных токенов.
   При превышении квоты API отказывает **до отправки** платного вызова.
3. Текущий маршрутизатор FastAPI возвращает ошибку валидации (400)
   для большинства путей и обобщённую ошибку (502) для некоторых
   исключений AI-анализа. Более точный HTTP 429 и единый UX
   обработки лимитов — отдельное изменение.
4. Если файл SQLite невозможно создать, открыть или изменить,
   новые платные запросы не отправляются (fail closed).
   Проверьте владельца/права каталога `PROMO_DATA_DIR`.
5. Для гарантии отсутствия двойной оплаты после частичного сбоя
   требуется PR #37 (кэш результатов): этот PR основан на его ветке.
   Одновременные обращения внутри одного процесса обрабатываются
   локальным lock в PR #37; межпроцессный cache lock не реализован.

Для существующего Time4VPS добавьте две переменные вручную в
`/etc/promoeditor/promoeditor.env`, создайте резервную копию перед
изменением и перезапустите **только** службу `promoeditor`.
Другие службы VPS, Caddy и RegionalResearch не трогайте.

Проверка без платных вызовов: `python -m pytest -q tests/test_ai_quota.py`.
