# PromoEditor — гибридная рекламная сборка (18.11.2026)

Основной рабочий процесс: **оригинальная техника + оригинальный логотип и чертёж + точные, вручную подтверждённые поля + художественный AI-фон**. Сборка происходит на сервере в одном SVG для каждого соотношения сторон, а PNG/JPEG рендерятся из того же SVG.

## Как использовать утверждённый ZubrTrail 500

1. Открыть PromoEditor и нажать **«ZubrTrail 500 · утверждённый эталон»**. Это отдельный набор проверенных заказчиком сведений от 18.11.2026, а не прежний тестовый демо-брив.
2. Загрузить исходное изображение жёлтого четырёхосного полуприцепа (предпочтительно PNG с прозрачностью), настоящий логотип ZUBR TRAIL и оригинальный технический чертёж; остальные ракурсы загрузить при необходимости.
3. Нажать «Проанализировать материалы» и проверить, какой файл выбран главным ракурсом, логотипом, чертежом и дополнительным изображением. Материалы реального заказчика **не** хранятся в публичном GitHub.
4. Гибридный режим выбран по умолчанию **только при наличии настроенного на сервере OpenAI API**. Он требует выбранного исходного фото и явного клика создания макета: два платных Images-запроса генерируют **только фон** под пропорции 4:3 и 9:16. Без API-ключа интерфейс автоматически выбирает бесплатный шаблонный режим.
5. Скачать ZIP: отдельные `corel_4x3.svg`, `corel_9x16.svg`, `poster_*.png`, `poster_*.jpg`, `brief.json`, исходники в `originals/`. Группы, текстовые объекты, технический рисунок и фон независимы и поддаются замене в CorelDRAW после импорта. Внутренние пиксели фотографии и AI-фона — растр, не вектор.
6. Старый режим AI-концепций (три проекта компоновки) доступен отдельно. Полные AI-растровые постеры доступны **экспериментально**, их технические детали и надписи нельзя считать точными или редактируемыми.

## Безопасность оплаченных ответов

Успешно сгенерированные платные изображения записываются в скрытый частный `.paid_visual_cache/` немедленно после каждого ответа. Если второй Images-вызов, растеризация, запись на диск или ZIP завершается ошибкой, **перезапуск того же идентичного запроса** повторно использует сохранённое, не выполняя дублирующих платных вызовов для уже сохранённых аспектов. Только после успешно готового ZIP записи удаляются и следующий новый запуск создаёт новый вариант. Повтор с изменённым брифом, моделью, фото или промптом имеет другой ключ кэша. Кэш временный: срок зависит от PROMO_JOB_TTL_SECONDS. Не следует отключать серверный учёт вызовов.

## Ограничения и выпуск

- Подтверждение цифр принадлежит пользователю. Никакие данные из рекламного примера или документа не заменяют поля другого проекта без его согласия.
- При большом числе характеристик рекламный лист показывает приоритетную часть списка; весь утверждённый перечень сохраняется в `brief.json` внутри ZIP. Проверяйте предупреждения о сокращённых блоках.
- Настоящие платные OpenAI Images-запросы в CI не выполняются. Также CI не заменяет ручную проверку CorelDRAW и чтение макетов на телефоне.
- Общий Time4VPS содержит RegionalResearch и работающий Caddy. Не запускать на нём standalone Docker/изменения глобального Caddy. Перед обновлением нужны резервная копия, тест памяти на реальном большом фото и возможность отката. Незавершённый PR #45 о лимите памяти **не объединять** без отдельной проверки.
