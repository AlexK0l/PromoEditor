# PromoEditor — один экран, один AI-арт-директор

Дата: 19.11.2026. Инженерный кандидат для проверки владельцем.

## Что изменилось в пользовательском пути

Основной экран показывает только необходимые действия: оригинальное фото товара,
название, рекламный тезис, цену/валюту, телефон, один переключатель
**«Оформить с помощью OpenAI»** и кнопку **«Создать промо»**.
Для ZubrTrail 500 есть отдельная кнопка утверждённого пресета: цена
**6 527 000 ₽ с НДС**, телефоны **+7 (951) 704-30-42 / 704-29-95**,
проверенные владельцем характеристики и экономика. Файлы техники, логотип
и чертёж загружаются оригинальными — они не опубликованы в GitHub.

Словарь внутренних алгоритмов, выбор между AI PRO/гибридом/шаблоном,
просмотр промпта, ручной отбор материалов, дополнительные ТТХ, чертежи,
отдельные 6 кнопок экспорта и редактор не исчезли, но раскрываются
**по желанию**, вне главного маршрута. Полный AI-растровый постер остаётся
экспериментальным инструментом, **не** маскируется под технически точный SVG.

## Четвёртый режим — художественная композиция + точные данные

В обычном включённом AI-режиме пользователь платит за:

1. **Один текстово-визуальный запрос OpenAI Responses**: арт-директор
   рассматривает копию оригинального фото и при наличии — стилевой эталон,
   выбирает композиции 4:3 и 9:16, типографическую иерархию, палитру и
   описание промышленной сцены. Никакие цены, телефоны или характеристики
   из AI-ответа не принимаются. Сервер валидирует все зоны по строгой
   JSON-схеме, проверяет коллизии и вместимость текста. Из трёх предложений
   выбирается макет с самым крупным полезным полем для техники.
   Повтор идентичного задания в пределах TTL использует частный
   content-addressed кэш плана — не оплачивает план дважды после ошибки ZIP.
2. **Два вызова OpenAI Images**, по одному на формат: только
   фотореалистичное художественное ОКРУЖЕНИЕ. Рекламируемая техника,
   чертёж, логотип и надписи не должны содержаться внутри AI-фона.
   Фон учитывает реальную выбранную AI область под товар и не содержит
   табличных/текстовых сведений.
3. **Детерминированный редактор SVG** создаёт отдельные группы/объекты:
   фотослой товара, AI-фон, логотип, исходный чертёж, векторный заголовок,
   8 важнейших ТТХ, габариты, преимущества, расчёт выгоды (если указан),
   подтверждённую цену и два телефона. Контраст проверяется сервером.
   Для автоматического гибрида добавлены тёмная рекламная шапка и
   отдельные красные акценты — без порчи исходных пикселей и геометрии.
   Из одного SVG получаются PNG и JPEG; форматы 4:3 и 9:16.
   Обе настоящие PNG-картинки видны на странице **сразу** после сборки,
   ZIP содержит исходники и `layout_spec.json`.

**Ограничение плотности:** в рекламных форматах может поместиться
не весь справочник ТТХ и габаритов (например, утверждённых 10 ТТХ).
Макет использует приоритетные первые 8 ТТХ и первые 4 габарита;
остальные сохраняются в `brief.json` в ZIP. Приложение предупреждает,
когда полный список не помещён. Нельзя утверждать, что в плакате
отображены все 10 пунктов, если видимы лишь 8.

## Точность и безопасность

- Исходная фотография и техчертёж — самостоятельные встроенные растровые
  SVG-объекты (не перерисованные OpenAI и не превращённые в полноценные
  векторные линии). Текст, плашки, фигуры — редактируемые векторы.
- OpenAI может ошибаться даже в художественном фоне: проверка реального
  результата остаётся обязательной. Запрещено выдавать полностью
  AI-постеры за эквивалент оригинальных чертежей и технических фактов.
- Запрос арт-директора получает изображение товара для анализа
  композиции; это отдельный платный запрос. **3 платных запроса на полный
  первый выпуск:** 1 Responses и 2 Images, без дополнительных расходов за
  локальные превью. Объём тарификации зависит от настроек/модели.
- Существующая отмена суточных лимитов PromoEditor не отменяет оплату,
  ограничения и бюджеты OpenAI, защиту API и лимиты памяти VPS.
- Общий Time4VPS ранее показывал 616 МиБ доступной RAM из-за активного
  RegionalResearch. Никакие изменения ветки на сервер не установлены.
  Без отдельной приёмки памяти и ручного теста CorelDRAW не выпускать
  на работающий сервер. Черновой PR #55 по изоляции рендеров не объединён.

## Проверки

Тесты без реальных платных вызовов: `tests/test_hybrid_art_director.py`,
`tests/test_hybrid_transaction.py`, `tests/test_calm_ui.py`,
`tests/browser_assets_smoke.py`, `tests/browser_ai_concepts_smoke.py`.
GitHub Actions предоставляет реальные desktop/mobile скриншоты
упрощённой страницы через CI artifact. Прежде чем объединять, проверить
этот UI по скриншотам и выполнить в тестовой среде один полный платный
запрос по вашим исходникам с контролем памяти/расходов.
