# Promo Studio — веб-генератор промышленной инфографики

## Генерация промо из формы с проверяемым промптом и исходниками CorelDRAW

1. Заполните компактную форму: фото товара, логотип, модель, характеристики, преимущества, цену и контакты.
2. Нажмите **«Сформировать промпт»**. Генерация промпта из формы выполняется программно, **без платного AI-вызова**. Текст можно проверить и отредактировать до 8000 символов. После изменения полей промпт становится устаревшим; перед генерацией он пересоздаётся автоматически.
3. Нажмите **«Создать PNG · JPEG · SVG»**. При включённом OpenAI текст промпта передаётся для генерации только художественного AI-фона/сцены (до двух платных Images API вызовов). ТТХ, цена и контакты всегда накладываются программно из данных формы, не рисуются ИИ. Без OpenAI создаётся шаблонное промо с оригинальным фото или демо; свободные пожелания без AI не меняют верстку произвольно.
4. Скачайте два размера: **4:3 (1440×1080) и 9:16 (1080×1920)**. Для каждого доступны **PNG, JPEG и послойный SVG**, а ZIP содержит все шесть файлов, `promo_prompt.txt`, `brief.json` и `CORELDRAW_README.txt`.

**CorelDRAW:** откройте `corel_4x3.svg` или `corel_9x16.svg` через **Файл → Импорт/Открыть**, при необходимости разгруппируйте и редактируйте надписи, таблицы, цену, контакты, графику, логотип и фотографии отдельно. Затем сохраните документ как **.cdr** в CorelDRAW; бинарный CDR не создаётся приложением напрямую. Шрифт **DejaVu Sans** обеспечивает близкую расстановку текста при переносе; при отсутствии шрифта CorelDRAW может заменить его. **Важное ограничение:** внутренние детали фотографии/AI-сцены нельзя редактировать как отдельные векторные кривые, хотя саму фотографию можно перемещать, заменять, обрезать и масштабировать как независимый объект.

**Конфиденциальность:** исходные фотографии и логотипы встраиваются внутрь SVG, поэтому ZIP с исходниками содержит их как часть SVG-файлов. Документы и стилевые референсы, не использованные как отдельные визуальные объекты, в ZIP не включаются. PNG/JPEG генерируются из того же SVG, поэтому композиция согласована.

## One-password sign-in for Time4VPS

On a configured Time4VPS server, replace Caddy's browser username+password dialog with one independent PromoEditor password (minimum 8 characters). After updating the app, run `bash /opt/promoeditor/deploy/time4vps/switch_to_password_login.sh` as root. The script activates fail-closed FastAPI login, verifies protected API access, then safely removes only PromoEditor's old Caddy Basic Auth. Session cookies are signed and HttpOnly Secure (12-hour expiry); passwords and signing secrets are kept in the root-owned `/etc/promoeditor/promoeditor.env` file. RegionalResearch is unchanged. See `deploy/time4vps/README.md` for backups and steps.

## Светлая и тёмная тема

В верхней панели редактора доступна кнопка переключения светлой и тёмной темы. Тема применяется к форме генерации, дополнительным настройкам, разделу редактирования готового промо и странице входа. Выбор сохраняется локально в браузере (localStorage), а при первом открытии используется настройка операционной системы. Переход между темами плавный (320 мс), кроме случая, когда в системе включено уменьшение анимации — тогда переключение мгновенное. При первоначальной загрузке тема применяется без анимации во избежание вспышки неправильных цветов. **Цвета итоговых PNG и содержимое canvas не меняются** при переключении интерфейса. Для тёмного режима на форме входа доступен тот же переключатель; до авторизации браузеру разрешено получить только безопасный скрипт `/theme.js`, остальные файлы и API защищены паролем.


## Рекламный PRO: очистка фона и иерархии (v5)

После сравнения реального ZubrTrail 500 с эталоном горизонтальный режим `reference_pro` изменён ещё раз:

- При отсутствии **подтверждённого реального** фона больше не рисуются условные силосы и промышленный пейзаж. Вместо них используется нейтральная светлая редакционная сцена из независимых SVG-фигур; реальный фон, если предоставлен, остаётся приоритетным.
- Исходная фотография товара занимает больше полезной ширины слева, не маскируется и не превращается в синтетическую картинку.
- Четыре рассчитанных экономических значения больше не сжимаются в сетку 2×2 на 35% ширины: теперь это одна строка с более крупными числами. Пользовательские подтверждённые тезисы занимают соседнюю область.
- Длинные подписи и технические значения остаются проверяемыми текстовыми SVG-объектами. Формат 9:16 продолжает использовать проверенную вертикальную композицию v3.

Это изменение **не добавляет** фотографического фона. Для уровня исходного эталона загрузите собственную промышленную фотографию или используйте опциональный AI-фон (с проверкой прав и корректности композиции).

## Рекламный PRO — отдельный стиль по композиции эталона

В переключателе стилей появился **«Рекламный PRO · как эталон»**. Он не заменяет прежние стили и не меняет контракт API.

- Новый SVG-движок `app/campaign_pro.py`: красно-белая шапка, диагональные ленты, крупный товар, фактические карточки ТТХ с векторными пиктограммами, чертёж (только если загружен), преимущества и рекламный CTA.
- Поле `style: "reference_pro"` включает стиль в `/api/generate` и `/api/prompt`. По-прежнему создаются два PNG, два JPEG, два SVG и ZIP. Все тексты и фигуры редактируются в CorelDRAW; фотографии — отдельные растровые элементы.
- Композиция похожа на эталон по иерархии и динамике, **но не копирует чужой логотип, фотографию, цифры, цену, телефон, утверждения или схему**. Отсутствующие блоки не придумываются, а отдают место фотографии.
- Реалистичный промышленный фон создаётся **только при включённом платном OpenAI**. Без него используется нейтральный фон.
- Чертёж и размерные стрелки не выдумываются из чисел: загрузите готовую проверенную схему. API принимает опциональные `proof_points` для явно подтверждённых фактов; интерфейс не добавляет такие сведения автоматически.

Для проверки: `python -m pytest -q tests/test_reference_pro.py tests/test_campaign_layout.py tests/test_corel_export.py`, затем весь тестовый набор и сборка Docker. Перед публикацией визуально проверьте оба размера и длинные тексты.
## Новый рекламный дизайн по эталонному сравнению

В стиле **«Рекламный · как эталон»** генератор PNG/JPEG/CorelDRAW SVG использует новую единую компоновку для 4:3 и 9:16:

- **Крупное изображение товара** в главной зоне, с аккуратным обрезанием только пустых белых/прозрачных внешних полей. Второе выбранное фото, если есть, остаётся отдельным небольшим заменяемым объектом.
- Насыщенный цветной заголовок, брендовый логотип и визуальная графика, набор отдельных векторных **карточек характеристик с пиктограммами** (только для реально предоставленных/одобренных ТТХ), панель габаритов и чертежа (если загружены), преимущества (только из формы), широкий CTA с ценой и телефонами (если они есть).
- Вместо пустых и фальшивых данных вроде «Характеристики уточняются» или придуманных преимуществ **скрываются блоки без проверенного содержания**. Освободившееся место занимает крупная фотография.
- Предыдущие переключатели цветов (премиальный, минимальный) сохраняются, но композиция теперь строится единым рекламным движком. SVG сохраняет отдельные текстовые, графические и растровые элементы, PNG/JPEG рендерятся из этого же SVG.
- Результат зависит от исходников: для максимального сходства с эталоном нужна качественная фотография товара в полный рост/ракурс, дополнительная фотография, настоящие ТТХ, логотип и цена/контакты. **Эталонное изображение не подтверждает достоверность данных** и не копируется в макет. ТТХ, полученные из документов AI-анализом, сначала нужно проверить и применить в форме.
- При отсутствии значений в форме макет остаётся законченным, но не создаёт факты или теххарактеристики из воздуха. Художественный фон можно запросить через OpenAI, но это отдельная платная услуга.

## Большие исходные фотографии: автоуменьшение только для анализа

Фотографии **6000×4000 px (24 Мп)** и другие исходники больше прежнего ограничения в 20 млн пикселей теперь принимаются при соблюдении безопасных пределов: **до 80 млн пикселей**, до **10 000 px по каждой стороне**, до **20 МБ на файл** и до **68 МБ суммарно**. Это ограничение на оригинал для безопасной генерации, а не на изображение, отправляемое AI.

- Для **локального анализа** резкости, цвета, разрешения и повторов создаётся временное превью максимум **300×300 px**; для **AI-оценки** — максимум **512×512 px**. Пропорции и EXIF-поворот учитываются. JPEG по возможности декодируется сразу в уменьшенном размере.
- Анализ **не перезаписывает оригинал**: SHA256, выбор изображения и исходные байты в `/api/generate` остаются неизменными. В отчёте указаны исходное разрешение, размер превью и предупреждение об уменьшении.
- Для генерации макета используется качественная рабочая копия размером **до 3200 px по стороне**; в SVG растровые слои могут дополнительно уменьшаться до 2000 px по стороне. При этом **оригинальные выбранные фотографии (без изменения байтов) включаются в ZIP в папку `originals/`**. Их можно использовать для печати или замены растра в CorelDRAW.
- Фотография **8840×6614 px (58,47 Мп)** автоматически обрабатывается, если её размер в байтах укладывается в 20 МБ. Изображения за пределами 80 Мп / 10 000 px по стороне, повреждённые файлы и файлы больше 20 МБ по-прежнему отклоняются во избежание перегрузки VPS.

## Увеличенный чертёж в рекламном PRO (4:3)

Если пользователь загрузил **двухпроекционный чертёж**, например боковой вид полуприцепа сверху и вид сзади снизу, горизонтальный рекламный макет показывает **увеличенный боковой вид**, взятый непосредственно из исходного файла. Это *кадрирование для рекламной вёрстки*, а не автоматически нарисованная или изменённая инженерная схема. Автоопределение применяет консервативную проверку распределения линий: чертежи без отчётливо выраженных двух проекций остаются целыми.

В полосе габаритов боковой вид получает отдельную большую область, а подтверждённые длина, ширина и высота выводятся крупными текстовыми SVG-значениями. Дополнительный ракурс больше не вытесняет чертёж из основной части блока.

Оригинальная выбранная фотография чертежа (JPG/PNG/WEBP) без каких-либо изменений байтов добавляется в ZIP как `originals/drawing.jpg` или другой исходный графический формат. Уменьшенное изображение в SVG предназначено только для рекламы и не заменяет полный исходный чертёж. PDF-чертежи по-прежнему преобразуются в изображение для макета.

## Автоматическое распознавание технического чертежа из фото

Если пользователь загрузил техническую схему JPG/PNG/WEBP через основной фото-блок, бесплатный **«Автовыбор»** теперь пытается определить её по **монохромному белому листу с тонкими линиями, распределёнными по площади изображения**. Это ограниченная локальная эвристика, не OCR и не гарантированное распознавание смыслового содержания. Подтверждённый чертёж автоматически назначается `selected_assets.drawing` и **исключается из выбора двух фотографий товара**. Другие файлы остаются фото.

Сервер отдаёт `auto_drawing: true`, а в интерфейсе появляется «Чертёж (распознан автоматически)» и отметка о назначении. Если изображение определено неправильно, в списке можно выбрать «Обязательно использовать» (оставить фотографией), «Не использовать» или «Использовать как чертёж» (ручное назначение), затем нажать «Пересобрать выбор».

Загруженный через отдельное поле чертёж или явно вручную назначенный файл всегда имеет приоритет перед автоматическим распознаванием. После изменения роли прежний отчёт больше не показывается как действительный: выбор заново появляется только после успешной пересборки. **Тот же файл не должен одновременно считаться «не включённым» и отображаться в новом макете как выбранный чертёж.** Изменение ролей не меняет оригинальных байтов загруженных файлов.

## Чертёж без дополнительных настроек

Поле **«Чертёж»** (JPG / PNG / WEBP / PDF) расположено в основном блоке загрузки рядом с фотографиями, документами и логотипом. Отдельно открывать дополнительные параметры больше не нужно.

Если пользователь уже загрузил техническую схему в общий список фотографий, выберите для неё **«Использовать как чертёж»** в выпадающем списке конкретного файла и нажмите **«Пересобрать выбор»**. Выбор обрабатывается сервером: исходник становится фактическим `selected_assets.drawing`, исключается из конкурса за роль главного фото и передаётся в экспортируемый SVG как технический чертёж. Перезагружать файл не требуется.

Автовыбор без платного AI оценивает техническое качество изображений, но **не гарантирует распознавание чертежей по содержимому**. Назначение роли вручную — явное и воспроизводимое действие. Для одного промоматериала можно принудительно назначить только один чертёж; конфликт двух обязательных чертежей возвращает понятную ошибку.

## Работа с несколькими исходными файлами

В единственной компактной форме можно загрузить **несколько фотографий товара, документов, логотипов и референсов**, добавляя файлы за несколько заходов. Список вложений показывает миниатюры изображений, название, размер и индивидуальную кнопку удаления. На каждый файл можно установить приоритет: «AI выбирает» (по умолчанию), «Обязательно использовать» (для документов — приоритет анализа) или «Не использовать». Размер одного файла — до **20 МБ**, всего до **16 файлов и 68 МБ**.

1. Заполните форму, загрузите материалы и нажмите **«Проанализировать материалы»**. При наличии OpenAI можно включить платную оценку всех фото/логотипов/референсов и документов (потребуется явное подтверждение, возможно несколько вызовов API). Без ключа бесплатный режим измеряет только разрешение, резкость, наличие прозрачности и повторы — он **не распознаёт ракурс и не понимает объект**.
2. Проверьте блок **«Что выберет система?»**: основное фото, до одного дополнительного ракурса, один логотип, чертёж, до двух референсов и список документов, использованных для анализа. Неиспользованные файлы показаны с причиной. Можно изменить приоритеты и нажать **«Пересобрать выбор»** — повторного платного анализа для прежних совпадающих файлов не требуется.
3. Сведения из PDF/Excel/Word/CSV отображаются **как предложения с указанием источника**, их нельзя автоматически считать достоверными. Если проверили — нажмите «Перенести предложенные ТТХ в форму» и подтвердите действие. Без подтверждения данные из документов не публикуются в тексте промо.
4. Нажмите **«Сформировать промпт»**: он включит имена выбранных и исключённых исходников и ограничения на использование. Промпт можно дополнительно отредактировать.
5. Нажмите «Создать PNG · JPEG · SVG»: сервер **повторно проверит исходные файлы** и применит выбор по ID/хешу, затем создаст оба формата **4:3 и 9:16** с PNG, JPEG и послойным SVG для CorelDRAW. ZIP включает **asset_selection.json** — отчёт об использованных/исключённых файлах. Все выбранные логотипы, фото и чертежи встраиваются в SVG отдельными заменяемыми растровыми объектами, а текст и фигуры остаются векторными.

Особенности: AI-оценка изображений и анализ документов могут стоить денег; она не проверялась в живом платном API в CI. Встроенный PNG/JPEG не становится векторным по частям; чтобы поменять деталь внутри изображения, используйте существующий редактор готового промо или инструменты CorelDRAW. Ни OpenAI, ни качество материалов не гарантируют автоматической истинности рекламных утверждений.

## Интерфейс PromoEditor

Доступен только **«Компактный»** вариант интерфейса. Главная страница `/` сразу открывает одностраничную форму; переключателя между дизайнами, дополнительных вариантов и вложенных страниц больше нет. Введите название продукта, прикрепите фото и при необходимости документы, укажите рекламный тезис и стиль. Остальные поля размещены в «Дополнительных настройках».

После генерации доступны PNG **4:3 (1440 × 1080)**, PNG **9:16 (1080 × 1920)** и ZIP.

В компактной форме есть отдельное необязательное поле **«Дополнительные действия над дизайном»** (до 1200 символов). Примеры: сделать фон светлее, добавить мягкую подсветку, оставить больше свободного пространства справа. Инструкции включаются в запрос генерации **обоих форматов** при активной опции OpenAI. Без OpenAI они сохраняются в `brief.json`, но не меняют готовый PNG. Текстовые блоки, характеристики, цена и логотип накладываются отдельно и не редактируются произвольными инструкциями. Поле не гарантирует точного выполнения любых пожеланий AI-моделью. Предпросмотр макетов отключён. Для визуализации через OpenAI API требуется серверный ключ.

## Редактирование готового промо (PNG)

Внизу единственной компактной страницы добавлен отдельный раскрывающийся блок **«Редактировать готовое промо»**. В него можно загрузить существующий PNG/JPG/WEBP (до 20 МБ) или открыть только что созданный PromoEditor вариант 4:3 / 9:16. Внутри редактора есть холст с визуальным просмотром исключительно для правок (отображение готовых изображений на основном экране генерации не возвращалось).

- **Ручное редактирование без AI:** добавить, переместить, изменить размер, удалить слой с новым текстом, фото или логотипом; закрыть выделенную область сплошным цветом; отменить/повторить; скачать отредактированный PNG оригинального разрешения.
- **Сохранение редактируемых слоёв:** «Сохранить редактируемый проект» выгружает локально файл `.promo.json` с исходным изображением и всеми вновь созданными слоями; затем можно открыть этот файл для точного последующего редактирования.
- **AI-изменение существующего рисунка:** пользователь выделяет прямоугольник на изображении инструментом «Область для AI», описывает требуемую замену, подтверждает отдельный **платный** запрос и получает новую версию изображения. Без выделения редактируется весь PNG. Сервер вызывает OpenAI Images edit с исходником и маской, возвращает исходное разрешение, вне непрозрачной маской закрытой области сохраняет исходные пиксели; исходный файл не перезаписывается. Выбор модели берётся из поля «Модель OpenAI», качество выбирается в редакторе.

**Ограничение обычного PNG:** текст, логотип и графические элементы уже объединены в растровое изображение, и их нельзя выделить как исходные слои. Для удаления встроенного элемента используйте закрытие фоном или AI-редактирование выделенной области, затем при желании добавьте новый редактируемый слой. Точность AI-замены не гарантируется — проверяйте надписи, технические характеристики и реальные детали техники. Сохраняйте `.promo.json` для повторного точного редактирования добавленных слоёв; ZIP генерации хранится отдельно. Доступ к OpenAI key остаётся на сервере за Caddy HTTP Basic Auth. Результаты серверного AI-редактирования хранятся по TTL.

## Обновлённый интерфейс (одноэкранная форма)

Вместо обязательного трёхшагового мастера используется единая страница: добавьте главное фото (можно перетащить), документы/логотип, впишите бренд или модель, рекламную фразу и преимущества, выберите один из трёх стилей и нажмите **«Создать оба формата»**. Остальные материалы и настройки скрыты в раскрывающихся разделах. Произвольные пожелания к оформлению влияют на AI-фон; числовые ТТХ, контакты и надписи отображаются только из подтверждённых полей.

Предпросмотр макетов **не показывается**. После генерации появляются кнопки скачивания PNG 4:3, PNG 9:16 и ZIP. При изменении данных готовые ссылки скрываются до повторной генерации, чтобы не перепутать версии. Кнопка «Пример заполнения» задаёт тестовые поля только по явному нажатию.

## 1. Быстрый запуск на Windows

1. Установите **Python 3.11–3.13** и откройте терминал в папке проекта.
2. Создайте окружение и установите зависимости:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

3. Без ключа уже доступна локальная сборка двух PNG. Для AI-генерации выполните `Copy-Item .env.example .env`, затем укажите `OPENAI_API_KEY=...` **в локальном файле `.env` на сервере**. Не отправляйте ключ в браузер или переписку.
4. Запустите:

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

5. Откройте в браузере **http://127.0.0.1:8000**.

Если PowerShell запрещает активацию виртуального окружения, запускайте `\.venv\Scripts\python.exe -m pip install -r requirements.txt` и затем `\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000`.

## 2. Запуск на Linux/macOS

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env  # необязательно для режима без AI
```

## 3. Упрощённый интерфейс PromoEditor

На первом экране теперь **одна компактная форма**, без боковых панелей, длинного мастера и изображений предпросмотра. Достаточно:

1. **Добавить фото товара** (PNG/JPG/WEBP до 20 МБ). По желанию прикрепить логотип и документы.
2. **Указать название продукта** — единственное текстовое обязательное поле — и добавить главный рекламный тезис. Отдельно можно написать пожелания к оформлению.
3. **Выбрать стиль** (контрастный, графитовый или минимальный) и нажать **«Создать два формата»**.

Если фотографии нет и OpenAI выключен, можно выбрать **«Заполнить пример»**: команда заполнит демонстрационный бриф и позволит создать тестовый комплект без платных запросов. Автоматически чужой демо-товар в чистую форму не подставляется.

В раскрывающихся **«Дополнительных настройках»** находятся бренд и категория, до четырёх коротких преимуществ, характеристики `Название | Значение`, другие преимущества, габариты, цена, контакты, условный сценарий окупаемости, второй ракурс, чертёж, стилевые референсы, выбор качества и акцентного цвета.

Если документы с ТТХ загружены, прямо под загрузкой появится кнопка **«Извлечь характеристики из документов»**. По умолчанию это локальное извлечение без платного вызова. Если явно включить «Использовать OpenAI для анализа документов», выполняется отдельный платный запрос. **Значения не копируются в макет автоматически**: проверьте их и нажмите кнопку применения в дополнительных настройках. Для PDF со сканами без текстового слоя в MVP нет OCR.

Текст пожеланий к оформлению в AI-режиме влияет на визуальные изображения (фон, атмосферу); точная раскладка текста выполняется существующим шаблоном. Без OpenAI пожелания сами по себе не меняют расположение блоков; для обычного режима выберите из трёх шаблонов. Отдельного свободного дизайнера макетов в версии 1.0 пока нет.

Опция OpenAI активна только если на сервере настроен `OPENAI_API_KEY`. **Создание комплекта с OpenAI — до двух платных запросов Images API** (по одному на размер), плюс опциональный отдельный вызов разбора документов. При отсутствии ключа доступна только сборка с исходными фотографиями или тестовым примером. API-ключ никогда не вводится через веб-форму.

После генерации доступны PNG, JPEG и SVG для CorelDRAW в обоих размерах плюс ZIP с промптом и проверяемым брифом. Предпросмотра готовых макетов в форме нет; проверьте скачанные изображения перед публикацией. Изменение полей скрывает устаревшие ссылки, пока не будет создан новый комплект.

## 4. Защита точности

**Данные из документов НЕ публикуются автоматически.** В основе финального постера — только то, что пользователь перенёс и подтвердил в полях формы. Генеративная модель не рисует ценники, заголовки, габариты, таблицы, контактные телефоны и не заменяет загруженный оригинальный логотип. Изображение исходной техники остаётся на макете, а OpenAI используется для атмосферы/фона. Если основного фото нет и AI создаёт вид техники, это помечается `AI-ВИЗУАЛИЗАЦИЯ` — такая картинка может отличаться от реального оборудования.

Расчёт экономики — **сценарий**, а не гарантированная доходность. В нём используются заданные пользователем цифры: дополнительная масса × километры × ставка за т/км × рейсы; затем вычитается разница в цене относительно аналога. Проверьте законные ограничения осевой нагрузки, полную массу, товарные паспорта, цену конкурента, единицы измерения и права на бренд перед публикацией.

## 5. Архитектура и API

- Backend: FastAPI, Python; Pillow — детерминированная верстка и масштабирование.
- Frontend: нативные HTML/CSS/JavaScript, без сборщика и внешних клиентских библиотек.
- OpenAI Images API: `client.images.generate(...)` или `client.images.edit(...)` с загруженными **стилевыми** референсами. Для плакатов выбираются исходные размеры изображения `1536×1024` и `1024×1536`, которые потом композиционно сводятся к точным 4:3 и 9:16.
- OpenAI Responses API: опционально извлекает факты из текста документов; формат — JSON Schema, источник остаётся недоверенным.
- `POST /api/inspect` — извлечение ТТХ из документов; `POST /api/generate` — формирование двух PNG и ZIP; `GET /api/config` и `/api/demo` — конфигурация и референсы.
- Примеры URL результата: `/files/{job_id}/poster_4x3.png`, `/files/{job_id}/poster_9x16.png`, `/files/{job_id}/promo_kit.zip`.

Ключ `OPENAI_API_KEY` существует **только на сервере**, никогда не передаётся в JavaScript. Файлы валидируются по форматам, ограничиваются 20 МБ на файл, 68 МБ суммарно, 16 файлов за запрос; на операции создания/AI-анализа есть простой лимит по IP (`PROMO_REQUESTS_PER_HOUR`, по умолчанию 20/час на процесс). Исходные документы/фото не сохраняются в `instance/jobs`. Финальные PNG и JSON хранятся локально, ссылка истекает через 2 часа; папки чистятся при новых генерациях. Для публичного сервера потребуются авторизация, единая система ограничений между процессами, проверка прав на файлы и внешний бюджетный лимит в панели OpenAI.

**API-расходы оплачиваются отдельно от подписки ChatGPT.** Версия проверена без API-ключа (все маршруты генерации через OpenAI тестируются моками), поэтому первый реальный API-вызов нужно проверить после настройки аккаунта, лимитов и API-ключа. Модели могут требовать подтверждения организации в OpenAI API.

Официальные руководства: [Image generation](https://developers.openai.com/api/docs/guides/image-generation), [Image edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit), [Responses API / File inputs](https://developers.openai.com/api/docs/guides/file-inputs).

## 7. Ограничения версии 1.0

- Макеты создаются по одному фирменному шаблону; требования «переставить все блоки произвольно» требуют отдельного редактора сетки.
- AI не гарантирует точность визуализированных механизмов. Для точной документации используйте исходные реальные фотографии.
- Нет OCR для сканированных PDF, нет извлечения графики с произвольной страницы, нет авторизации для публичного хостинга.
- Логотип лучше загружать PNG с прозрачностью. SVG из недоверенных источников намеренно не принимается.
- PNG и JPEG не являются послойными. Для редактирования скачайте SVG, откройте в CorelDRAW и сохраните как CDR.
