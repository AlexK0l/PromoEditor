# Promo Studio — веб-генератор промышленной инфографики

## One-password sign-in for Time4VPS

On a configured Time4VPS server, replace Caddy's browser username+password dialog with one independent PromoEditor password (minimum 8 characters). After updating the app, run `bash /opt/promoeditor/deploy/time4vps/switch_to_password_login.sh` as root. The script activates fail-closed FastAPI login, verifies protected API access, then safely removes only PromoEditor's old Caddy Basic Auth. Session cookies are signed and HttpOnly Secure (12-hour expiry); passwords and signing secrets are kept in the root-owned `/etc/promoeditor/promoeditor.env` file. RegionalResearch is unchanged. See `deploy/time4vps/README.md` for backups and steps.

## Интерфейс PromoEditor

Доступен только **«Компактный»** вариант интерфейса. Главная страница `/` сразу открывает одностраничную форму; переключателя между дизайнами, дополнительных вариантов и вложенных страниц больше нет. Введите название продукта, прикрепите фото и при необходимости документы, укажите рекламный тезис и стиль. Остальные поля размещены в «Дополнительных настройках».

После генерации доступны PNG **4:3 (1440 × 1080)**, PNG **9:16 (1080 × 1920)** и ZIP.

В компактной форме есть отдельное необязательное поле **«Дополнительные действия над дизайном»** (до 1200 символов). Примеры: сделать фон светлее, добавить мягкую подсветку, оставить больше свободного пространства справа. Инструкции включаются в запрос генерации **обоих форматов** при активной опции OpenAI. Без OpenAI они сохраняются в `brief.json`, но не меняют готовый PNG. Текстовые блоки, характеристики, цена и логотип накладываются отдельно и не редактируются произвольными инструкциями. Поле не гарантирует точного выполнения любых пожеланий AI-моделью. Предпросмотр макетов отключён. Для визуализации через OpenAI API требуется серверный ключ.

## Редактирование готового промо (PNG)

Внизу единственной компактной страницы добавлен отдельный раскрывающийся блок **«Редактировать готовое промо»**. В него можно загрузить существующий PNG/JPG/WEBP (до 20 МБ) или открыть только что созданный PromoEditor вариант 4:3 / 9:16. Внутри редактора есть холст с визуальным просмотром исключительно для правок (отображение готовых изображений на основном экране генерации не возвращалось).

- **Ручное редактирование без AI:** добавить, переместить, изменить размер, удалить слой с новым текстом, фото или логотипом; закрыть выделенную область сплошным цветом; отменить/повторить; скачать отредактированный PNG оригинального разрешения.
- **Сохранение редактируемых слоёв:** «Сохранить редактируемый проект» выгружает локально файл `.promo.json` с исходным изображением и всеми вновь созданными слоями; затем можно открыть этот файл для точного последующего редактирования.
- **AI-изменение существующего рисунка:** пользователь выделяет прямоугольник на изображении инструментом «Область для AI», описывает требуемую замену, подтверждает отдельный **платный** запрос и получает новую версию изображения. Без выделения редактируется весь PNG. Сервер вызывает OpenAI Images edit с исходником и маской, возвращает исходное разрешение, вне непрозрачной маской закрытой области сохраняет исходные пиксели; исходный файл не перезаписывается. Выбор модели берётся из поля «Модель OpenAI», качество выбирается в редакторе.

**Ограничение обычного PNG:** текст, логотип и графические элементы уже объединены в растровое изображение, и их нельзя выделить как исходные слои. Для удаления встроенного элемента используйте закрытие фоном или AI-редактирование выделенной области, затем при желании добавьте новый редактируемый слой. Точность AI-замены не гарантируется — проверяйте надписи, технические характеристики и реальные детали техники. Сохраняйте `.promo.json` для повторного точного редактирования добавленных слоёв; ZIP генерации хранится отдельно. Доступ к OpenAI key остаётся на сервере за Caddy HTTP Basic Auth. Результаты серверного AI-редактирования хранятся по TTL.

## Обновлённый интерфейс (одноэкранная форма)

Вместо обязательного трёхшагового мастера используется единая страница: добавьте главное фото (можно перетащить), документы/логотип, впишите бренд или модель, рекламную фразу и преимущества, выберите один из трёх стилей и нажмите **«Создать оба формата»**. Остальные материалы и настройки скрыты в раскрывающихся разделах. Произвольные пожелания к оформлению влияют на AI-фон; числовые ТТХ, контакты и надписи отображаются только из подтверждённых полей.

Предпросмотр макетов **не показывается**. После генерации появляются кнопки скачивания PNG 4:3, PNG 9:16 и ZIP. При изменении данных готовые ссылки скрываются до повторной генерации, чтобы не перепутать версии. Кнопка «Пример заполнения» задаёт тестовые поля только по явному нажатию.

## 1. Быстрый запуск на Windows

1. Установите **Python 3.11–3.13** и откройте терминал в папке проекта.
2. Создайте окружение и установите зависимости:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

3. Без ключа уже доступна локальная сборка двух PNG. Для AI-генерации выполните `Copy-Item .env.example .env`, затем укажите `OPENAI_API_KEY=...` **в локальном файле `.env` на сервере**. Не отправляйте ключ в браузер или переписку.
4. Запустите:

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

5. Откройте в браузере **http://127.0.0.1:8000**.

Если PowerShell запрещает активацию виртуального окружения, запускайте `\.venv\Scripts\python.exe -m pip install -r requirements.txt` и затем `\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000`.

## 2. Запуск на Linux/macOS

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env  # необязательно для режима без AI
./run.sh
```

Открыть http://127.0.0.1:8000. Сервис по умолчанию доступен **только локально**, не публикуется в интернет.

## 3. Упрощённый интерфейс PromoEditor

На первом экране теперь **одна компактная форма**, без боковых панелей, длинного мастера и изображений предпросмотра. Достаточно:

1. **Добавить фото товара** (PNG/JPG/WEBP до 20 МБ). По желанию прикрепить логотип и документы.
2. **Указать название продукта** — единственное текстовое обязательное поле — и добавить главный рекламный тезис. Отдельно можно написать пожелания к оформлению.
3. **Выбрать стиль** (контрастный, графитовый или минимальный) и нажать **«Создать два формата»**.

Если фотографии нет и OpenAI выключен, можно выбрать **«Заполнить пример»**: команда заполнит демонстрационный бриф и позволит создать тестовый комплект без платных запросов. Автоматически чужой демо-товар в чистую форму не подставляется.

В раскрывающихся **«Дополнительных настройках»** находятся бренд и категория, до четырёх коротких преимуществ, характеристики `Название | Значение`, другие преимущества, габариты, цена, контакты, условный сценарий окупаемости, второй ракурс, чертёж, стилевые референсы, выбор качества и акцентного цвета.

Если документы с ТТХ загружены, прямо под загрузкой появится кнопка **«Извлечь характеристики из документов»**. По умолчанию это локальное извлечение без платного вызова. Если явно включить «Использовать OpenAI для анализа документов», выполняется отдельный платный запрос. **Значения не копируются в макет автоматически**: проверьте их и нажмите кнопку применения в дополнительных настройках. Для PDF со сканами без текстового слоя в MVP нет OCR.

Текст пожеланий к оформлению в AI-режиме влияет на визуальные изображения (фон, атмосферу); точная раскладка текста выполняется существующим шаблоном. Без OpenAI пожелания сами по себе не меняют расположение блоков; для обычного режима выберите из трёх шаблонов. Отдельного свободного дизайнера макетов в версии 1.0 пока нет.

Опция OpenAI активна только если на сервере настроен `OPENAI_API_KEY`. **Создание комплекта с OpenAI — до двух платных запросов Images API** (по одному на размер), плюс опциональный отдельный вызов разбора документов. При отсутствии ключа доступна только сборка с исходными фотографиями или тестовым примером. API-ключ никогда не вводится через веб-форму.

После успешной генерации появляется блок скачивания: **PNG 1440×1080 (4:3), PNG 1080×1920 (9:16), ZIP** с обоими изображениями и проверяемым JSON-брифом. Предпросмотра готовых макетов в форме нет; проверьте скачанные изображения перед публикацией. Изменение полей скрывает устаревшие ссылки, пока не будет создан новый комплект.

## 4. Защита точности

**Данные из документов НЕ публикуются автоматически.** В основе финального постера — только то, что пользователь перенёс и подтвердил в полях формы. Генеративная модель не рисует ценники, заголовки, габариты, таблицы, контактные телефоны и не заменяет загруженный оригинальный логотип. Изображение исходной техники остаётся на макете, а OpenAI используется для атмосферы/фона. Если основного фото нет и AI создаёт вид техники, это помечается `AI-ВИЗУАЛИЗАЦИЯ` — такая картинка может отличаться от реального оборудования.

Расчёт экономики — **сценарий**, а не гарантированная доходность. В нём используются заданные пользователем цифры: дополнительная масса × километры × ставка за т/км × рейсы; затем вычитается разница в цене относительно аналога. Проверьте законные ограничения осевой нагрузки, полную массу, товарные паспорта, цену конкурента, единицы измерения и права на бренд перед публикацией.

## 5. Архитектура и API

- Backend: FastAPI, Python; Pillow — детерминированная верстка и масштабирование.
- Frontend: нативные HTML/CSS/JavaScript, без сборщика и внешних клиентских библиотек.
- OpenAI Images API: `client.images.generate(...)` или `client.images.edit(...)` с загруженными **стилевыми** референсами. Для плакатов выбираются исходные размеры изображения `1536×1024` и `1024×1536`, которые потом композиционно сводятся к точным 4:3 и 9:16.
- OpenAI Responses API: опционально извлекает факты из текста документов; формат — JSON Schema, источник остаётся недоверенным.
- `POST /api/inspect` — извлечение ТТХ из документов; `POST /api/generate` — формирование двух PNG и ZIP; `GET /api/config` и `/api/demo` — конфигурация и референсы.
- Примеры URL результата: `/files/{job_id}/poster_4x3.png`, `/files/{job_id}/poster_9x16.png`, `/files/{job_id}/promo_kit.zip`.

Ключ `OPENAI_API_KEY` существует **только на сервере**, никогда не передаётся в JavaScript. Файлы валидируются по форматам, ограничиваются 20 МБ на файл, 68 МБ суммарно, 16 файлов за запрос; на операции создания/AI-анализа есть простой лимит по IP (`PROMO_REQUESTS_PER_HOUR`, по умолчанию 20/час на процесс). Исходные документы/фото не сохраняются в `instance/jobs`. Финальные PNG и JSON хранятся локально, ссылка истекает через 2 часа; папки чистятся при новых генерациях. Для публичного сервера потребуются авторизация, единая система ограничений между процессами, проверка прав на файлы и внешний бюджетный лимит в панели OpenAI.

**API-расходы оплачиваются отдельно от подписки ChatGPT.** Версия проверена без API-ключа (все маршруты генерации через OpenAI тестируются моками), поэтому первый реальный API-вызов нужно проверить после настройки аккаунта, лимитов и API-ключа. Модели могут требовать подтверждения организации в OpenAI API.

Официальные руководства: [Image generation](https://developers.openai.com/api/docs/guides/image-generation), [Image edit API](https://developers.openai.com/api/reference/python/resources/images/methods/edit), [Responses API / File inputs](https://developers.openai.com/api/docs/guides/file-inputs).

## 6. Тестирование

```bash
python -m pytest -q
node --check app/static/app.js   # при наличии Node.js
```

14 автоматических проверок: форматы, безопасный деморежим, загрузка/валидация фото, извлечение CSV/XLSX/DOCX, PDF-чертёж, пределы объёма, ROI, URL-ограничения, переполнение текстов, мок OpenAI Images API. Визуальные образцы проверены при 1440×1080 и 1080×1920, интерфейс проверен на широком и мобильном viewport. Реальная биллинговая проверка OpenAI API не выполнялась — ключ не был предоставлен.

## 7. Ограничения версии 1.0

- Макеты создаются по одному фирменному шаблону; требования «переставить все блоки произвольно» требуют отдельного редактора сетки.
- AI не гарантирует точность визуализированных механизмов. Для точной документации используйте исходные реальные фотографии.
- Нет OCR для сканированных PDF, нет извлечения графики с произвольной страницы, нет авторизации для публичного хостинга.
- Логотип лучше загружать PNG с прозрачностью. SVG из недоверенных источников намеренно не принимается.
- Оба файла PNG не являются послойными исходниками. Для полноценного редактирования нужен экспорт PPTX/SVG, который можно добавить следующим этапом.
